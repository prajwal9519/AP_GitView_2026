# CP-4 PostgreSQL execution plans

This directory is populated by `../run_cp4_benchmark.py`.

The runner writes one `query_NN_<description>.json` file per statement (35 total). Each file contains the first run's PostgreSQL `EXPLAIN (ANALYZE, BUFFERS, VERBOSE, FORMAT JSON)` output, including actual plan nodes, buffer activity, planning time, and execution time.

Do not create or hand-write plans. They must be generated by running the query against PostgreSQL.
